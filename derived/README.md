# derived/

Exports computed from the records in `data/`. **Never edit them by hand.**
Regenerate with `python scripts/build_release.py`; CI runs it with `--check`
and fails if anything here is stale or was not built by the script. The
outputs depend on the records alone, with no dates, commits or versions, so
the check is stable across commits. Release metadata (tag, commit, DOI)
belongs only in a release bundle's `manifest.json`
(`docs/releases-and-occurrences.md`).

There are three layers:

| layer | files | what for |
|---|---|---|
| **records** | `*.jsonl`: one record per line, sorted by ID, keys sorted, UTF-8 | the full normalised source, prose included |
| **tidy tables** | `tables/*.tsv` | **the analytical form**: one entity or one kind of measurement per table, one row per thing, keyed by Atlas IDs |
| **summary** | `taxon_layers.tsv` | a human-facing overview, deliberately not tidy (several compounds in one cell) |

Plus `summary.json` (schema version, record counts, generator versions,
schema checksums) and `SHA256SUMS`.

`derived/` is not a release. Releases are tagged bundles built from it, and
none exists yet.

## `tables/`: the tidy relational tables

The YAML records are the normalised source; these are views of them,
generated by `scripts/build_tables.py`. A test checks that every table is
rectangular and that every key joins to its entity table. Prose (notes,
author statements, unresolved items) is deliberately absent: it is
provenance, not something to compute with, and it is in the JSONL. A field
is structured when it is compared, filtered, joined or validated; otherwise
it stays prose.

| table | one row per | key |
|---|---|---|
| `taxa`, `taxon_synonyms` | taxon; synonym | `taxon_id` |
| `references` | reference | `reference_id` |
| `compounds`, `compound_double_bonds` | compound; double bond | `compound_id` |
| `genomes`, `genome_annotations` | assembly; gene set | `genome_id`, `annotation_id` |
| `searches` | dated search | `search_id` |
| `observations` | observation: type, taxon, name as reported, reference, context | `observation_id` |
| `observation_experiments` | observation × trial (a pooled record has several rows) | `observation_id`, `experiment_id` |
| `chemical_samples` | chemical measurement × material | `observation_id` |
| `chemical_components` | compound in a chemical measurement, detected or not | `observation_id`, `compound_id` |
| `chemical_values` | measured value of a component | `observation_id`, `compound_id` |
| `behavioural_assays` | behavioural contrast: effect, significance, dose, response | `observation_id` |
| `behavioural_stimuli` | compound in a treatment or comparator lure, with amount and purity | `observation_id`, `role` |
| `behavioural_setups` | trap and dispenser of the treatment and the comparator | `observation_id`, `role` |
| `electrophysiology_responses` | antennal reading | `observation_id`, `compound_id` |
| `evidence_classes` | taxon × compound × evidence class, with its supporting observations (`scripts/build_evidence.py`; rules in `docs/evidence-classes.md`) | `taxon_id`, `compound_id`, `evidence_class` |

Empty cells are missing values. The files load as they are into a data frame,
or into DuckDB:

```sql
SELECT o.taxon_id, c.compound_id, count(*) AS records
FROM 'derived/tables/chemical_components.tsv' c
JOIN 'derived/tables/observations.tsv' o USING (observation_id)
WHERE c.detected = 'true'
GROUP BY ALL ORDER BY ALL;
```

## `taxon_layers.tsv`: the taxon × layer matrix

One row per Atlas taxon, sorted by name.

| column | from |
|---|---|
| `taxon_id`, `species` | the taxon record |
| `genome_status` | see the vocabulary below |
| `assembly_accession`, `assembly_name`, `assembly_level` | the taxon's genome record (`data/genomes/`) |
| `annotation_id`, `pep_fasta_md5` | its first gene set: the archived Ensembl Rapid Release set and the MD5 of its `-pep.fa.gz` from `md5sum.txt`, so a download can be checked |
| `pheromone_status` | see the vocabulary below. A summary label only: the columns after it keep female chemistry, emission, behaviour and antennal evidence apart |
| `chemical_materials` | the sample materials of the taxon's `chemical_measurement` records (`gland_extract`, `effluvium`, `ovipositor_extract`): gland content and emission are different evidence |
| `compounds_detected_in_females` | every compound with `detected: true` in the taxon's `chemical_measurement` records |
| `compounds_tested_negative` | every compound with `detected: false` in those records. A compound in both columns was found in one study or population and not in another; the records say which |
| `n_chemical_measurement`, `n_behavioural_response`, `n_electrophysiology` | record counts |
| `references` | the references behind the taxon's observations |
| `search_basis` | the search records a status rests on, when it rests on a search |

`genome_status`:

| value | means |
|---|---|
| `assembly` | a genome record exists |
| `no_assembly_in_census` | a dated census of the family (`search_basis`) found no nuclear assembly. **Not evidence that none exists now** |
| `not_searched` | no census covers this taxon |

`pheromone_status`, in order of precedence:

| value | means |
|---|---|
| `female_chemistry_curated` | at least one curated `chemical_measurement` detects a compound in females |
| `attraction_curated` | curated behavioural records only: males attracted to synthetics, no female chemistry curated |
| `found_not_curated` | a dated search (`search_basis`) found literature that no Atlas record holds yet |
| `searched_not_found` | a dated search found nothing. **Not evidence that none exists** |
| `not_searched` | no record and no search |

A status of `searched_not_found` or `no_assembly_in_census` always names its
search; that "not found" is never inferred from missing records is a test
(`test_taxon_layers_never_infers_not_found`).

## Where the searches came from

The searches of 2026-10-23 (`data/searches/`):
- **Assemblies:** the NCBI Datasets genome report for Sesiidae (21 assemblies, 11 species; alternate haplotypes not recorded as genomes).
- **Gene sets:** Ensembl Rapid Release FTP listings and `md5sum.txt`. Rapid Release is archived, and IDs on the new Ensembl platform were not checked.
- **Pheromones:** web and PubMed searches, then primary abstracts. **The Pherobase could not be read** (it sits behind a bot check), so `searched_not_found` rows were not checked against it.

Only Palaearctic and East Asian taxa appear. That reflects where genomes and
pheromone work exist, not the family's diversity: Sesiidae have more than
1,500 species, many tropical (`docs/knowledge-gaps.md`).
